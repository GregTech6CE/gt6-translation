# MC百科

## 信源信息

- 地址：https://www.mcmod.cn
- GT6 条目：https://www.mcmod.cn/class/455.html
- GT6 非官方版：https://www.mcmod.cn/class/2281.html
- GT6CE：https://www.mcmod.cn/class/32292.html
- 搜索：站内搜索支持中英文 mod 名；也可以用 `site:mcmod.cn "<关键词>"`。

## 涵盖内容

- 中文 mod 条目：简介、物品/方块/材料列表、合成表、教程、汉化链接。
- 整合包条目：包含的 mod、魔改说明、任务线。
- 评论区/教程区有玩家常用译名和俗称。
- 早期教程区（`/post/<id>.html`，多转载自 1.2.5–1.6.4 时期的 MCBBS 图文教程）：保存了 GitHub 官中语言文件出现之前的老版本民间汉化词表与合金配方。当 GT6 早期语料中的整批同模组译名与 1.7.10+ 官方 `zh_CN.lang` 系统性不符时，可用此类教程做整表译名指纹核验（例如《[冶金3 物品详细介绍](https://www.mcmod.cn/post/59.html)》完整记录了 `Infuscolium=精金`、`Adamantine=血石`、`Atlarus=深金`、`Tartarite=熔火之石`、`Orichalcum=自然之石`、`Hepatizon=幽魂结晶`、`Angmallen=神圣之金` 等整套 GT6 沿用旧译）。

## 注意事项

- 条目由玩家编辑，可能过时；注意页面标注的 mod 版本。
- 物品页的“材料”通常指合成材料，不一定等于 GregTech 的材料（Material）概念。
- 评论和教程是玩家观点，不是官方设定；只能作为“社区用法”或“早期民间汉化来源”的证据。
- 汉化下载链接可能指向旧版本，优先用 GitHub 仓库。
- 抓取 `/post/<id>.html` 教程正文时，HTML 常压缩为单行超长段落；使用 `rg` 检索前需先剥离 HTML 标签或附带 `--max-columns 0`，避免长行词表被省略。
- 引用条目 URL，不要复制大段正文。
